# NeoBank

Java banking-system project focused on custom data structures, transaction workflows, account operations, transfer queues, undo stacks, and approval-oriented flows.

## Focus

- Hash-table based account/customer lookup
- Linked-list transaction history
- Queued transfers and pending requests
- Undo/redo-oriented operations
- Separation between domain objects and system orchestration

## Status

Academic systems project. Sensitive database exports, compiled output, credentials, and local configuration are intentionally excluded from this public showcase.
